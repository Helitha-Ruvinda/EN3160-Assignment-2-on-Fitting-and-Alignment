# EN3160 Assignment 2 — Fitting and Alignment

This repository contains Python implementations for EN3160 Assignment 2, covering fundamental computer vision techniques using OpenCV.

## Topics

1. **Blob Detection** — Laplacian of Gaussian (LoG) and scale-space extrema detection.
2. **Line and Circle Fitting** — RANSAC-based model estimation and optimization.
3. **Image Homography** — Perspective transformation and image blending.
4. **PCB Image Alignment** — SIFT feature matching, homography estimation, and image differencing.

## Technologies

- Python
- OpenCV
- NumPy
- Matplotlib
- SciPy

## Repository Structure

- `q1_blob_detection.py` — Sunflower blob detection.
- `q2_ransac.py` — Line and circle fitting.
- `q3_homography.py` — Perspective image overlay.
- `q4_pcb_alignment.py` — PCB alignment and difference analysis.
- `images/` — Input images.
- `results/` — Output images and visualizations.
