# EN3160-Assignment-2-on-Fitting-and-Alignment
Python implementations for EN3160 Assignment 2: Fitting and Alignment, covering Laplacian of Gaussian (LoG) blob detection, RANSAC-based line and circle fitting, homography-based image overlay, and SIFT-based PCB image alignment and differencing using OpenCV, NumPy, Matplotlib, and SciPy.
